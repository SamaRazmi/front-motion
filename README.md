## 📖 درباره پروژه

**Motion** یک وب‌سایت مدرن، پویا و تعاملی است که با تمرکز بر **انیمیشن‌های روان**، **تجربه کاربری جذاب** و **عملکرد بالا** طراحی و توسعه داده شده است.

این پروژه با استفاده از جدیدترین تکنولوژی‌های وب ساخته شده و هدف آن ارائه‌ی یک تجربه‌ی کاربری سریع، زیبا و واکنش‌گرا در تمام دستگاه‌ها است.

### 🎯 فلسفه پروژه

> "هر حرکت، یک پیام است."
> 
> در Motion، هر انیمیشن، هر ترنزیشن و هر تعامل، با دقت طراحی شده تا حس **زنده بودن** و **پویایی** را به کاربر منتقل کند.

## ✨ ویژگی‌های کلیدی

- ⚡ **Next.js 16** با App Router و Server Components
- ⚛️ **React 19** با جدیدترین APIها و Concurrent Features
- 🎬 **انیمیشن‌ها و تعاملات روان** برای تجربه‌ای زنده
- 🎨 **Tailwind CSS 4** برای استایل‌دهی سریع و مدرن
- 🎠 **Swiper 14** برای اسلایدرها و کاروسل‌های حرفه‌ای
- 🎯 **Lucide React** و **React Icons** برای آیکون‌های برداری
- 📱 **طراحی Mobile-First** و کاملاً Responsive
- 🌙 **پشتیبانی از RTL** و طراحی بومی‌سازی‌شده
- 📘 **TypeScript 5** به‌صورت کاملاً Type-Safe
- 📦 **Bundle Analyzer** برای بهینه‌سازی حجم باندل
- 🔍 **ESLint** با کانفیگ رسمی Next.js
